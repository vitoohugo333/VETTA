# UI Premium VETTA

Esta pasta contém a nova autoridade visual da Refatoração 360. `model.js` preserva contratos financeiros e armazenamento; `store.js` controla apenas estado de interface/navegação; `premium.css` define a gramática visual; `main.js` será o entry point da experiência. A interface legada permanece no repositório apenas como referência/rollback durante a substituição, e não deve ser empilhada sobre esta camada.
